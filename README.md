# Excel Practice for Data Analysis

I'm using this repository to practice Excel for data analysis. The first two workbooks use the same ten job roles to explore how experience, annual salary, and bonuses compare across roles.

## Workbooks

| Workbook | What to try |
| --- | --- |
| [1. Introduction to formulas](./1_Formulas_Intro.xlsx) | Add the maximum bonus to the annual salary, calculate the bonus as a percentage of salary, and see how cell references change when you copy a formula down. |
| [2. Introduction to functions](./2_Functions_Intro.xlsx) | Calculate averages with `AVERAGE`, count entries with `COUNT` and `COUNTIF`, and combine two conditions with `AND`. The `Errors` sheet shows examples of common formula errors. |

## Try an exercise

What is the average experience across the ten roles?

1. Download the [functions workbook](./2_Functions_Intro.xlsx) and open the `Data` sheet in Excel.
2. Select cell `C14`, enter `=AVERAGE(C3:C12)`, and press **Enter**.
3. Check your result against cell `C14` on the `Final` sheet. Both should give **5.3 years**.
